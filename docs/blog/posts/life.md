## 不要把克服恐惧理解为压住情绪

你写到：如果情绪失控，需要主动抑制。

这里需要稍微修正一下。

你的目标不是不许自己害怕，失落，忌妒或者难过，也不是靠意志力把情绪按回去，因为这样很容易变成另一种自我控制：

```
我连难过都不应该
为什么别人能坚持吗，我不行
我怎么又情绪化了
```

真正需要训练的是：**我允许恐惧出现，但不把恐惧当作命令**

例如：
```
我现在害怕这个项目失败----情绪
所以我今天不能开始----这是情绪发出的命令
我可以害怕，同时先做20分钟----这是主体性行动
```

你要学的不是“没有恐惧”，而是带着恐惧行动，并在行动中修正认识。

## 用实践的方法缩小恐惧

恐惧不能主要靠相通解决，因为你越坐在那里想象，堵车，失败，被拒绝，工作找不到，退学后悔等风险会无限膨胀。

回避能够在短期内缓解焦虑，但是可能让一个人越来越依赖回避。医学资料也罢回避视为创伤和焦虑问题种的重要表现之一。面对恐惧，通常采用的不是一下子把人扔进最害怕的环境，而是建立层级，循序渐进地接触。

建立一个恐惧实践表：
任务                      预期恐惧                最坏结果
去陌生咖啡馆坐30分钟        3/10                  路上麻烦，去了也不舒服
给同行发一封请教邮件        5/10                  对方觉得我水平差
独立完成一个小实验          6/10                  跑不通，证明我不适合科研
投一个机器人实习            7/10                  建立被拒绝，很丢人
和导师讨论方向和退出方案      9/10                  被否定，指责，人生失控

原则不是从9分开始，而是从3/4分开始

每次记录四件事：
1. 我行动前预测会发生什么
2. 我有多害怕
3. 我最终做了什么
4. 现实是否真的像预测那么糟

这其实也是一种调查研究：**不靠头脑里的想象认识世界，而是通过行动获取材料**

## 你的小事恢复主体性的思路是对的，但要稍微调整
你的减脂，看书，做小项目，这是对的，但是要警惕将它们重新变成另一场考试：
```
每天必须运动
必须读完多少页
项目必须做出厉害成果
否则就证明我又失败了
```

这样，主体性训练就又会变成绩效考核

建议同时建立三类小任务：

**身体控制感**
固定起床时间，散步，力量训练，规律吃饭
（目的不是证明意志力，而是让身体重新获得稳定节奏）

**自主选择**
每天至少做一件不是因为“应该”，而是因为“我选择”的事

```
出门走哪条路
决定读哪篇论文
```

**不确定性训练**
每周做一件结果不可控的小事

```
发一封可能得不到回复的邮件
投一个不确定能否通过的岗位
去一个陌生的地方
发布一个不完上的项目
```

主体性不只是“完成计划”，还包括**承受别人的拒绝，事情失败和计划变化**

## 关于博士，暂时不需要一次豪赌解决
你判断先在自己不适合立刻退学，我认为这是清醒的，退学不应当被当作勇敢的证明，继续读博也不应当被当作证明坚持的仪式。

可以先进行一个六周的双规调查：

1. 当前博士，只完成明确的，最低限度的阶段任务
2. 对机器人，强化学习，每周完成一个可展示的小交付
3. 每周联系或者申请一定数量的RA，实习或者合作机会
4. 记录两条路线分别带来的经历，进展，兴趣和现实机会
5. 六周后根据材料判断，而不是根据某天的情绪判断

你需要调查的不是：退学是否是正确答案？

而是：当我持续投入机器人方向时，我是否愿意面对其中的枯燥，失败和不确定的部分？当博士课题变得更可控，得到一些反馈，我是否仍然不愿意做？我能否获得RA，实习或者工作的现实入口？继续读博与退出，各自真实的成本是什么？

这才是亲口尝李子，而不是坐在房间里反复想象李子的味道。

## 最后，我对你最大的恐惧的概括

你的核心恐惧可能是：

**如果我不再按照别人认可的道路前进，如果我主动选择却失败了，我会失去控制，失去认可，失去爱，并发现真实的自己其实什么也不是**

而你要逐渐建立的新认识是：

1. 我可以做错选择，也可以重新选择
2. 我可以被别人失望，拒绝或者不理解，但这不等于我没有价值
3. 我不需要通过学历，成功或者某个人的爱获得存在资格
4. 我可以一边害怕，一边调查，一边实践，一边调整路线

你并不是什么都做不好。更准确地说，你过去非常擅长在有规则，有标准答案的环境中生存，现在正在学习另一种以前没人教过你的能力：自己确定方向，并在没有把握的时候继续行动。

**这不代表你失败了，而是代表你终于开始从”完成别人设计的人生“，过渡到”参与设计自己的人生“
