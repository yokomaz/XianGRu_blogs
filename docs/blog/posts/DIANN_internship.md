# 这是我记录在上海创智学院 点睛实验室的实习

# 第二天 2026-09-01
今天早上骑电动车去创智，发现单程一个半小时的通勤时间确实有点长，而且还是自己骑电动车，路上的很多情况都需要操心，因此未来需要大力降低骑电动车去创智学院的计划（还是坐地铁舒服，但是坐地铁总是控制不住玩手机，对眼睛的压力很大）。不过骑电动车有个好处，可以欣赏沿途的风景，毕竟差不懂要纵穿整个上海的繁华区域，偶尔还能在桥上看看日落，看看黄浦江，看看江边的各类活动，还是蛮不错的。初步计划，可以每周五下班骑自行车回来，或者每周五骑电动车上下班。

买的4k 27寸大屏幕今天早上到位了，有一说一4k的分辨率的屏幕还从来没有用过，用在nvidia-spark上，各类软件的图标还是蛮小的，还是调整到了1080p的分辨率，看上去图标也比较大，字体比较容易看，对眼睛的压力小。

Nvidia-Spark确实是强大的AI服务器，现存128G，内存4TB，并且体积就跟一盒饼干的体积差不多大，价格在淘宝上看要34000多RMB，确实让人能感觉到科技的力量，能把这么强悍的计算性能和存储性能放在这么小的一个盒子里。搞完屏幕，键盘，鼠标之后，配置了miniconda，相比于anaconda，miniconda更加简洁，只包含了python和一些必要的软件包，没有全套anaconda3那么臃肿。然后配置了codex和claude code，记忆里是不能直接安装npm的，先安装了nvm，然后通过nvm管理的npm和node.js安装了codex和claude。claude安装完后要去~/.claude.json里添加一行 `"hasCompletedOnboarding": true` 从而绕过区域限制。看上去claude的判断区域就是看ip在某个列表里，然后通过这个参数来控制是否使用这个列表对比。

然后去找新认识的博士生赵欣彦，雷宜达，叶宇翔问了一下关于电机的事情，看上去是要一个USB-CAN线来提供控制，UART线来调试，一个48V的能够提供稳定直流电的电源来供电，已经整理成可能需要购买的物料了，明天再整理一下需要什么内容，到时候跟叶老师去申请购买和报销。

差不多今天就到这里了，明天见！

下午在创智学院，今天的主要工作是对要买的物料进行了调查，说实话测试电机需要USB-CAN线以及直流电源。USB-CAN转换器好办，我买了三个，结果发现达妙电机他们自己有开发这个转换器，我买的是别的厂家的，不知道能不能用，如果协议允许应该是能用的。电机的话，我调查了四个电机的型号，然后跟叶老师进行了交流，创智还是有钱啊，好几千的可编程式电源说买就买，不过我推荐的那个电源，本身支持的电压和电流范围比较广，之后如果要做别的测试的话也是够用的。同时我也买了一个正点原子的DP100电源，也是可编程的电源，感觉在极客圈很受欢迎啊，外观颜值也很高，也能满足大部分的使用情况。到时候要记得开专票找人报销。

临结束的时候，我接上UART和HL线，调试了电机的参数，好消息是电机能够运行，但是坏消息是，我用CAN-HL控制的时候，有的时候好像能听到电机里边在转，但是外侧这个银灰色的盘不转。我需要看看这种无刷电机的结构，同时看看他的上位机是怎么运行的，如何和电机通信这样子。

复旦这边的课题，我感觉是有可能做的，但是所有的事情都得我自己来做，从定义问题，到收集数据，制作数据集，设置模型结构，训练模型，消融实验等，可能这也是我前两年没有成绩的原因吧，我从来没有想过这套流程，我大概也是最近才开始开窍的。好难，感觉我从小到大，都是后半程才开窍，这样感觉真的很累的，心理压力也大。我希望我能拿到学位，然后做我想做的事情，就比如这种电机的控制，我现在还不清楚我是因为刚开始学而兴奋，还是别的。从阶段来讲，我现在在战略防御期间，需要稳扎稳打我的根据地，就是我对于电机的认识理解，然后逐步掌握控制电机的能力，静待战略相持阶段的到来，要坚定自己的认识。

# 第四天 2026-09-03
今天主要是推进了达妙电机在调试时候，有内部转子转，外部结构不转的问题。熟悉了电机的调试流程，熟悉了如何使用达妙电机调试助手进行电机调试的整体流程，同时也查看了底层串口通信的基础信息，包括使能信号与失能信号的数据，以及不同控制模式在串口信号中的数据类型。目前已经可以通过调试助手来实现速度模式的控制，接下来需要查看如何通过python的串口通信协议，来执行对电机的控制。整体上，周四在查看电机调试相关的手册以及使用方法，明天需要查看通过代码来控制电机的方法。

# 第五天 2026-09-04
周五通过电机的上位机，跑通了电机的MIT控制模式，同时熟悉了电机的指令控制的方法。这种电机的指令控制方法是每次发送一个控制指令，电机返回一个电机状态指令，如果想要不断控制，则需要不断发送控制指令。上位机目前能够发送定时的控制指令，但是控制指令的参数尚不清楚如何设置，因为扭矩仿佛很大一般，需要深入的学习。

跟叶老师约了officehour，讨论了将VLA结合到Cryo-ET的可能性。考虑到可以使用Cryo-ET来控制在样品成像阶段的帧数量，以及未来重构的tomogram质量，也许可以有VLA结合的机会。需要检查一下实验室冷冻电镜数据的格式与内容，是否符合VLA模型微调或者训练的结果，同时思考一下如何建模。

# 第六天 2026-09-07
今天用python和codex实现了对于电机的位置控制，主要功能包括对电机施加位置，程序通过定时发送控制指令，实现从原始位置到目标位置到顺滑转动，保持恒定力矩的转动。目前通过测试发现可以实现稳定力矩输出，同时能够实时监控电机位置，速度，力矩，电流，电压，功率等数据，下一步考虑将读取到的数据进行保存。目前的问题发现，如果想检测电机的电流，目前的方案是粗糙的观察电源的输出电流，电源的输出电流与电压的读取频率在18Hz左右，而电机的控制频率可以达到200Hz，所以需要考虑这种数据对齐，功率的话也是粗略地使用W=UI进行了计算。

明天要和叶老师约一个讨论，看看电机测试的方案，目前能够实现实时的数据监测，下一步应该是设计一个机械臂来打印并安装到电机。同时有以下一些问题：
1. 电机的位置是否需要对齐。考虑到之前lerobot的电机在启动之前，需要进行校准，放置机械臂活动度超出范围导致的物理损伤。
2. 控制频率是否需要降低，考虑到ESN和MIT的推理速度，测试后可以将控制频率控制在100Hz左右。

明天开始看VLA相关的论文，开始组织实验室数据，进行课题的思考。
