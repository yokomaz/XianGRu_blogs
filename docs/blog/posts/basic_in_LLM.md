# Large Language Model（LLM）

在学习MiniMind项目的过程中，我感觉到有一些LLM领域内通用的知识，可以单独拿出来整理成一个博客，这样在记录MiniMind的学习过程中，就不需要再重复的介绍相关的概念。因此产生了撰写这篇博客的想法。

## LLM的发展
自从2017年的论文《Attention is all you need》提出了transformer架构之后，大语言模型逐渐走入人们的视野。从2023年，ChatGPT横空出世，向人们展示了大语言模型的强大能力。从早期的网页端的ChatGPT的聊天窗口，到如今的小龙虾（OpenClaw），Ansthropic的Claude code，OpenAI的Codex等多种多样的智能体。这些能够帮助我们提高效率的工具背后，都指向了同一个概念：大语言模型。
